## TS-01 — Typer les pipelines MongoDB avec `PipelineStage[]`

**Contexte :** 6 usages de `any` dans les pipelines d'agrégation MongoDB de `RoundRepository.ts` et `TournamentPlayersDeckRepository.ts`. Ces `any` sont fonctionnellement corrects mais empêchent la vérification TypeScript des étapes de pipeline. Mongoose v7 exporte `PipelineStage` pour couvrir exactement ce cas.

**Critères d'acceptation :**
- [ ] Dans `RoundRepository.ts` : remplacer `any[]` par `PipelineStage[]` pour les 4 usages (lignes 67, 95, 114, 168)
- [ ] Dans `TournamentPlayersDeckRepository.ts` : idem pour les 2 usages (lignes 163, 224)
- [ ] Ajouter `import type { PipelineStage } from 'mongoose'` dans les deux fichiers
- [ ] `npm test` passe à 100%, `tsc --noEmit` sans erreur

**Effort :** XS  
**Dépendances :** Aucune
